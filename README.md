# E-Commerce-Sales-Performance-Analysis
## 📌 Project Overview

E-Commerce Sales & Performance Analysis is an end-to-end Data Analytics project that transforms raw and unclean e-commerce data into a structured dataset and meaningful business insights.

The project starts with raw Excel data, which is cleaned and transformed using Python and Pandas. The cleaned data is then imported into a SQL database for analysis, and finally connected to Power BI to create an interactive dashboard.

The project focuses on analyzing sales performance, orders, products, categories, cities, payment methods, order status, and profitability.

## 🎯 Project Objectives

- Clean and transform raw e-commerce data.
- Handle missing, duplicate, invalid, and inconsistent records.
- Create new columns for sales, net amount, profit, and time-based analysis.
- Store the cleaned data in a SQL database.
- Perform business analysis using SQL queries.
- Create an interactive Power BI dashboard.
- Analyze sales and profit across different business dimensions.
